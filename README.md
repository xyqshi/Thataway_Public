# Thataway: bug reports and feature requests

This is the public tracker for **Thataway**, the iPhone app that picks a hidden place nearby and shows you only an arrow and a distance until you arrive.

- **Found a bug?** Open an issue with the *Bug report* template, or use **Settings → Report a bug** in the app.
- **Have an idea?** Open an issue with the *Feature request* template, or use **Settings → Request a feature** in the app.
- **Want something that is already listed?** Add a 👍 to that issue instead of opening a new one. The most-wanted things get done first.

Everything here is public. Please do not post personal details such as your address or where you were walking.

The app's source code is not in this repository.
